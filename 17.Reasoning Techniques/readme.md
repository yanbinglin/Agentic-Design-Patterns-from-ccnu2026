# 第 17 组｜Reasoning Techniques 推理技术

本目录收录《高级数据库技术》课程第 17 组的教材节选、章节笔记、汇报大纲、课件迭代和课堂演示。汇报用“会想 → 会查错 → 会动手 → 会协作”串联 CoT/ToT、自我纠正与程序辅助、ReAct、多智能体辩论与搜索，再用推理扩展定律解释质量、延迟和成本如何取舍，以 Deep Research 展示这些技术如何组合成一条工作流。

## 参考资料

- [《深入理解 AI Infra：量化分析与系统设计》](AI-Infra-Book%20%281%29.pdf)，李博杰著。根据封面与前言，本书从计算、显存、带宽与通信等约束出发介绍训练和推理基础设施。它可补充本章关于推理预算、系统延迟和部署成本的讨论。
- [《深入理解 AI Agent：设计原理与工程实践》](AI-Agents-in-Depth-zh-CN.pdf)，李博杰著。根据封面与目录，本书从模型、上下文和工具构成的智能体出发，讨论提示设计、记忆、检索与工具等工程问题，可用来扩展对智能体系统的理解。

快速入门可以先读章节笔记，遇到术语或图示再回教材核对；准备课堂展示时，可把最终版 PPT 与汇报稿对照阅读。想了解数据库课程中的应用，可以直接看页码导读里的数据库智能体案例。
